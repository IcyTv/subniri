# Application icons

The Fileberg, Iceout, Avalaunch, and Snowconf SVG icons were generated by
OpenAI GPT-6.1 Sol using hand-authored SVG code, not an image-generation model.

Fileberg's folder geometry is adapted from Phosphor Icons' `folder-open` icon:
<https://github.com/phosphor-icons/core>. The Phosphor MIT license is preserved
in `LICENSE-Phosphor`.

Nix installs each application's SVG under `share/icons/hicolor/scalable/apps/`
and renders PNG alternatives at 16, 32, 128, and 256 pixels during the build.
Desktop entries reference the icon by its extensionless application name.
